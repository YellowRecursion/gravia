# Версии зависимостей плагинов

Вопрос: как автор плагина объявляет совместимые версии других плагинов?

Владелец согласовал словарь ID → диапазон с npm-синтаксисом. Только ID не
позволяли проверить совместимость; только точные версии ограничивали применение
совместимых обновлений. Выбрана Semver 3.0.0 для строгих версий и npm-диапазонов,
без собственного парсера. Dependencies хранит неизменяемую копию словаря.

Проверены JSON round-trip, валидация, границы диапазонов, `0.x`, предрелизы и
build metadata; 148 тестов Domain прошли. Проверка подключённых плагинов и
фиксация точных версий расчёта ещё не реализованы.

Контракт и источники: [манифест плагина](../docs/plugins.md#манифест).
