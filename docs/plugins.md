## Границы первого среза

- Первый проверяемый сценарий — hello world: плагин подключается и пишет строку
  в журнал Gravia. Нод, `describe` и расчётных вызовов в нём нет.
- Менеджер плагинов делается сразу, а не временная команда разработчика.
- Проверяются оба способа запуска: управляемый Gravia и ручной.
- Включённые управляемые плагины запускаются при открытии проекта; при закрытии
  проекта плагины выключаются.
- Сценарий проверяется двумя реализациями: минимальным скриптом на чистом Python
  и тем же сценарием через SDK. Это показывает, что контракт реализуем без SDK,
  и что именно снимает SDK.
- После hello world первый этап возможностей — только ноды. Собственные настройки
  приложения/проекта, оптимизаторы, единицы и определения свойств плагинами
  не добавляются; их будущий API не утверждён.

## Менеджер и проект

- Менеджер — отдельное окно, как настройки.
- Список плагинов относится к проекту: добавить папку, включить/выключить,
  видеть состояние подключения. Для ручного режима показывается адрес.
- Плагин — папка с `plugin.json`. Манифест задаёт идентичность и команду запуска:
  `id`, `version`, `command`, `arguments`. Точная схема манифеста открыта.
- Путь к папке внутри проекта хранится относительно корня проекта (OWN-37).
  Политика для папок вне проекта не выбрана.
- Формат хранения списка плагинов в проекте не выбран. Паспорт проекта
  не переводится в v2; конкретный способ записи ещё открыт.
- Несколько копий Gravia работают одновременно для разных проектов (OWN-43).

## Подключение

- Gravia слушает loopback; плагин подключается клиентом.
- Порт выбирается заново при каждом запуске Gravia. Адрес показывается при
  каждом подключении (OWN-40).
- Управляемый режим: Gravia запускает процесс и передаёт адрес аргументом
  командной строки. Пользователь ничего не настраивает.
- Ручной режим: пользователь запускает программу сам и передаёт ей показанный
  адрес.
- Управляемый процесс принадлежит Gravia. Внешний процесс Gravia не завершает.
- Если плагин представился чужим ID или несовместимой версией протокола,
  Gravia отвечает ошибкой, закрывает соединение и показывает состояние «Ошибка».

## Протокол v0

- JSON-RPC 2.0, UTF-8, одно сообщение на строку. Переводы строк внутри строк JSON
  экранированы и границу сообщения не ломают.
- `hello` — запрос плагина: `protocol`, `id`, `version`. Gravia сверяет ID
  с ожидаемой записью и версию протокола.
- `log` — уведомление: `level`, `message`. Категория журнала выводится из ID
  плагина, а не присылается плагином.
- stdout/stderr процесса остаются диагностикой запуска и падения, а не основным
  каналом журнала.
- Аутентификация в v0 не решена; доступ ограничен loopback.
- Таймауты, предельный размер сообщения и поведение при переполнении открыты.

## Отложено

- `describe`: в первый срез не входит. Может ли он одновременно быть
  инициализацией — открытый вопрос.
- Схема описания ноды: порты, переменное число потоков, свойства, единицы.
- Форма вызовов расчёта: один пакетный метод или отдельные одиночный и пакетный.
- Числовые буферы и memory-mapped files.
- MATLAB-адаптер.
- Обработка изменений исходников во время расчёта; по указанию владельца
  пока не проектируется.
