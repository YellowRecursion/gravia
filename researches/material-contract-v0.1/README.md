# Эталонные структуры и арифметика контракта v0.1

Спецификация: [material-stream-contract-v0.1.md](../../docs/material-stream-contract-v0.1.md).

Это исполняемый пример предложенного API, а не готовая интеграция. Он не меняет и не запускает пользовательские модели, не загружает веса и не выполняет научную валидацию химии. Внешних NuGet-зависимостей нет.

```powershell
dotnet run --project MaterialContract.csproj
```

`Contract.cs` задаёт формы данных; `Conversions.cs` — единицы, массово-мольное преобразование и выделение продуктов; `Program.cs` проверяет численные примеры и отказ для некорректных данных. Тесты группировки используют синтетический состав с различающимися долями, чтобы обнаружить ошибку порядка PIONA.

Records и ReadOnlyMemory сами не гарантируют неизменность исходного массива: будущий runtime должен владеть буферами или копировать их при публикации. Полная валидация shapes, реестр свойств, исполнение PropertyPlan, IPC, CAPE-OPEN-мост и вызовы реальных моделей в этом примере не реализованы. Допуски примера относятся к арифметике, а не задают допуск кинетической модели.

Предположение аддитивности объёмов в функции плотности является явным; это дополнительная модель свойства, не универсальное физическое тождество.
